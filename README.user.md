# Regos ИКПУ — инструкция для пользователя

Программа обновляет в **REGOS.Online** коды **ИКПУ** (MXIK / `icps`), признак **маркировки** (`is_labeled`) и ставку **НДС**. Коды ИКПУ программа берёт из справочника **Tasnif** (soliq.uz) по штрихкодам товаров.

Это не установка REGOS и не замена кассы. Нужны интернет и доступ к вашей базе REGOS.

---

## Что нужно для работы

1. Файл программы: `Regos-IKPU-1.0.0.exe` (или другая версия с тем же именем).
2. **Токен интеграции** из REGOS.Online (локальный токен или OAuth каталога — как выдала ваша интеграция).
3. Стабильный интернет: программа обращается к серверам Regos и Tasnif.

Node.js и программирование **не нужны**. Дважды щёлкните по `.exe`.

Рядом с программой появятся служебные папки: база прогресса, журнал, сохранённые настройки. Не удаляйте их, пока идёт обновление.

---

## Первый запуск

1. Положите `.exe` в отдельную папку (например `C:\Regos-IKPU`) и запустите его.
2. В блоке **Подключение** вставьте **токен интеграции**.
3. Тип интеграции:
   - **Локальный токен** — обычный случай. Поля Client ID и секрет не нужны.
   - **OAuth каталога** — заполните Client ID и секрет клиента, если так настроена ваша интеграция.
4. Нажмите **Сохранить ключи**. Вверху должен появиться признак, что токен есть.

Настройки в блоке **Параметры** сохраняются сами.

---

## Как выбрать, что обновлять

### Группа товаров

- По умолчанию — **все группы** (весь каталог).
- Чтобы ограничить работу, найдите группу по названию или ID.
- Кнопка **×** снова выбирает все группы.
- Включите **Включать товары из дочерних групп**, если нужно обработать и вложенные папки каталога.

Выбранная группа действует на загрузку, поиск ИКПУ, запись в Regos, НДС и ручное обновление.

### ИКПУ

| Режим | Когда использовать |
| --- | --- |
| **Обновлять все** | Перезаписать ИКПУ у всех найденных в Tasnif товаров |
| **Только пустые коды ИКПУ** | Заполнить ИКПУ только там, где в Regos его ещё нет |
| **Не обновлять ИКПУ** | Не трогать коды; можно обновить только маркировку |

### Другие параметры

- **Обновлять is_labeled по данным Tasnif** — поставить признак маркировки, если в Tasnif товар маркируемый.
- **Пропускать удалённые товары** — не трогать удалённые позиции.
- **Пропускать услуги** — не трогать услуги, только товары.

Если выключены и обновление ИКПУ, и `is_labeled`, полное обновление через Tasnif делать не нужно — программа предупредит.

## Обновление ИКПУ из Tasnif (основной сценарий)

Рекомендуемый путь для обычной работы:

1. Выберите группу (или все группы) и режим ИКПУ.
2. Нажмите **Полное обновление**.

Программа по очереди:

1. Загружает товары из Regos.
2. Ищет ИКПУ в Tasnif по штрихкоду (если штрихкода нет — по уже указанному ИКПУ).
3. Записывает результат в Regos **только после успешного ответа** сервера.

Это может занять много времени на большом каталоге. Не выключайте компьютер и не отключайте интернет.

### Кнопки запуска

| Кнопка | Что делает |
| --- | --- |
| **Полное обновление** | Заново загружает каталог и проходит Tasnif + запись в Regos |
| **Продолжить** | Продолжает прерванную работу **без** повторной загрузки каталога |
| **Стоп** | Останавливает после текущего пакета (не мгновенно) |
| **Загрузить из Regos** | Только скачать товары в локальную базу |
| **Поиск в Tasnif** | Только поиск кодов |
| **Обновить Regos** | Только запись уже найденных кодов в Regos |

**Продолжить** появляется, если предыдущий запуск остановили. Если нужно заново взять актуальный каталог из Regos — используйте **Полное обновление** или сначала **Загрузить из Regos**.

## НДС

Блок **НДС** ставит **одну** выбранную ставку всем товарам выбранной группы (или всему каталогу).

- Товары, у которых эта ставка уже стоит, пропускаются.
- Прогресс поиска ИКПУ при этом не меняется.
- **Стоп** завершает текущий пакет.

Ставки подгружаются из Regos (например «без НДС» или 12% — как настроено у вас в системе).

---

## Ручное обновление

Если Tasnif не нужен, можно самим задать значения для группы или всего каталога:

1. **Записать ИКПУ** — один и тот же код ИКПУ всем выбранным товарам.
2. **Записать is_labeled** — признак маркировки **Да** или **Нет**.

Уже совпадающие значения пропускаются. Эти две операции независимы: одна кнопка пишет только код, другая — только маркировку.

## База данных и журнал

В блоке **База данных** видны счётчики товаров по этапам:

| Статус | Смысл |
| --- | --- |
| Ожидает | Товар загружен, поиск в Tasnif ещё не сделан |
| Готов | ИКПУ найден, ждёт записи в Regos |
| Обновлён | Успешно записано в Regos |
| Пропущен | По текущим настройкам менять нечего |
| Не найден | В Tasnif нет ИКПУ |
| Ошибка Tasnif | Сбой запроса к Tasnif, можно повторить позже |
| Ошибка | Сбой записи в Regos, можно повторить позже |

- **Обновить счётчики** — перечитать статистику.
- **Очистить базу** — стереть локальный прогресс. Сам каталог в REGOS.Online не удаляется. После очистки для ИКПУ из Tasnif снова нужна загрузка из Regos.

**Журнал** внизу окна показывает ход работы. Текстовые файлы журнала за каждый день лежат рядом с программой в папке `logs`.

## Если что-то пошло не так

- **Нет токена / ошибка входа** — проверьте токен, тип интеграции и кнопку «Сохранить ключи».
- **Группы не загрузились** — проверьте интернет и права интеграции; перезапустите программу.
- **Много «Не найден»** — у товаров нет штрихкода 8–14 цифр, либо такого GTIN нет в Tasnif. Можно заполнить ИКПУ вручную.
- **Программа «зависла» на Стоп** — дождитесь окончания текущего пакета; принудительно закрывать окно лучше только если прошло несколько минут без движения в журнале.
- **Windows спрашивает про неизвестного издателя** — это обычное предупреждение для портативной программы без цифровой подписи. Запускайте только файл, полученный из доверенного источника.

---

## Чего программа не делает

- Не создаёт товары в Regos.
- Не меняет цены, названия и штрихкоды (кроме выбранных полей: ИКПУ, маркировка, НДС).
- Не работает без интернета.
- Не «отменяет» уже записанные в Regos изменения одной кнопкой — ошибочные значения нужно править в REGOS.Online или повторным запуском с нужным режимом.

При сомнениях сначала выберите **одну небольшую группу** и проверьте результат в REGOS.Online.
